# AiCAD: тэмдэглэлтэй план → цэвэр DWG

Захиалагч оффисын план дээр улаан, цэнхэр өнгөөр "энд ийм юм" гэж зурж, бичиж явуулдаг. Энэ хэрэгсэл түүнийг уншаад AutoCAD-д нээгддэг цэвэр зураг гаргана.

- **Суурь план:** тэнхлэг, багана, хана, хаалга, өрөөний нэр, хэмжээс
- **Тэмдэглэл:** тусдаа layer-т цэвэр тэмдэгт болгож зурна
- **Тодорхойгүй зүйлс:** асуултын жагсаалт болгон гаргана

Оролт нь дараах гурвын аль нэг байж болно:
- хэвлэсэн зургийн утасны зураг;
- PDF;
- DWG.

> Зарчим: **ноорог = санаа, бичсэн тоо = нарийвчлал, каталог = бодит хэмжээ.**
> Тоог хэзээ ч таамаглахгүй. Уншиж чадаагүй, утга нь тодорхойгүй тоо бүрийг асуулт болгоно.

## Утасны зургийн ажлын урсгал (`tsukuda_cad/`)

| Модуль | Үүрэг |
|---|---|
| `photo.py` | Зургийг эргүүлэх, гэрлийг жигдлэх, багана илрүүлэх. **Тэнхлэгийн хэмжээсээр homography** тооцож пикселийг мм руу шилжүүлнэ. Fit-ийн алдаа нь уншсан хэмжээсийг давхар шалгана. |
| `vectorize.py` | Хэвлэмэл бэхийг хэвтээ, босоо шугам болгоно: давхар ханыг хуваах, координатыг бүлэглэх, тэнхлэгт snap хийх, булангуудыг хаах. Мөн харандааны шугамыг хасаж, хаалганы нумыг RANSAC-аар яг тааруулж, баганыг тэнхлэгийн огтлолцолд байрлуулна. |
| `markup.py` | Улаан тэмдэглэлийг цэвэр тэмдэгт болгоно. Бичсэн тоо байвал хамгийн ойрын хана эсвэл тэнхлэгээс яг тэр зайд байрлуулж, жинхэнэ DIMENSION зурна. |
| `dxfout.py` | Стандарт layer-ууд (A-GRID, A-WALL, A-DOOR, A-COLUMN, A-DIM, T-MARK, T-NOTE, T-CHECK), япон текстийн загвар, 1/100 хэмжээсийн загвар. |
| `render.py` | Шалгах зургууд: CAD-ийг зураг дээр давхарлах, зураг болон CAD-ийг зэрэгцүүлэх. |
| `run_photo_job.py` | Бүх алхмыг дарааллаар нь ажиллуулна. |

Ажиллуулах:

```bash
python -m tsukuda_cad.run_photo_job path/to/job
```

`job/job.json` файлд хуудаснаас **уншсан** мэдээлэл байна (жишээ: `examples/job.example.json`):
- эргэлт;
- тэнхлэгийн хэмжээс;
- өрөөний нэр;
- хаалганы ойролцоо хүрээ;
- тэмдэглэлийн зүйлс, тэдгээрийн тоо.

Геометрийг бүгдийг зурагнаас хэмждэг. Уншлагын хэсгийг дараа нь Claude API (vision + structured output) хийнэ.

Гаралт (`job/out/`):
- `plan_base.dxf`: суурь план;
- `plan_final.dxf`: суурь план + тэмдэглэл + асуултууд;
- `check.json`: тоо, тэдгээрийн эх сурвалж, асуултууд;
- `compare.png`.

DWG рүү ODA File Converter-ээр хөрвүүлнэ.

## `tools/`

Эхний прототипууд байна:
- PDF annotation унших;
- скан ↔ DWG бүртгэх;
- DWG дээр telecube-ийн тэмдэглэлийг хэрэглэх.
